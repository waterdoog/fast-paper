## 2. 我核实过、你的版本说对了的地方（放心保留）

- **A.5 撤回 fabrication / absorption。** 代码证据：`src/lib/agent.js:458` ask_agent 把该卡全部 planted 句子记为"已见"，不管回复里有没有出现；`agent.js:524` list_store 返回 60 字符预览但不记"已见"，只有 read_store 在第 530 行记；`src/lib/timeline.js:238` countAbsorbed 在原始 HTML 字符串上匹配数字，CSS 里的数值也能命中；`agent.js:107` 每拍新建 stats，跨拍曝光归零。所以"bounded 只看到四分之一的错误信息却 fabricate 58 次"很可能是记账造成的：D 臂通过 list 预览看到了值但没被记录，于是被算成"凭空捏造"。Yu 摘要里的 58-vs-1 不能用。

- **F.2 对 "~19k more tokens" 的批评。** bounded 减 open 的 token 差是 formation 对比，不是 Store 对 Sandbox，记到 semantics 头上不成立。属实。
- **Eq. (2) 与 0.181 / 0.314。** 代数正确；用四格均值验算：A−D = 0.181，B−C = 0.315（四舍五入 0.314），ΔF = 0.248，ΔS = 0.0665。
