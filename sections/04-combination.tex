\section{From a binary comparison to a configuration problem}
\label{sec:combination}

Once the bundle is unpacked, the question changes shape. It is no longer which corner
wins; it is which point in $(F,S,A)$ a given setting should hold. Three binary axes give
eight configurations, and no deployed network is a corner of them: a roster with an
introduction protocol is public on formation for whoever a broker can reach and private
for everyone else; an enterprise workspace is private on formation and fully open on
semantics.

\paragraph{The first result of the decomposition is that the space is smaller than it
looks.} A configuration search is only a search if more than one dimension moves the
outcome. On the task family we ran, the three weights are $0.248$, $0.066$ and $0$
on requirement $F_1$ (\S\ref{sec:evidence}), and the third is not small---it is
indistinguishable from two neutral lines of text. \textbf{An axis with zero weight is not a
dimension.} Eight configurations collapse to four. Semantics survives---$0.066$, interval
$[+0.012, +0.119]$---but it is charged at 11k tokens an episode, so on this task family the
four collapse in practice to a choice on formation with a priced option attached.

That collapse is a finding, not a failure of the framework, and it is the kind of finding
only a decomposition can produce: a study that compared the two corners would have
reported one diagonal---$0.181$ or $0.314$, depending on which pairing it happened to
call public and private---and had no way to learn that one third of the bundle does
nothing. We
report it rather than restoring the eight-way search, because the honest next question is
sharper than an optimisation. \textbf{Is the space two-dimensional everywhere, or only
here?}

\paragraph{Scenarios are the test of whether the weights are constants.} The collapse
above was measured on a single task class: facts held by different agents, aggregated
into one deliverable. That class is maximally favourable to formation---reach is
literally what it asks for---and maximally unfavourable to semantics, since there is no
shared artifact to co-edit. If the three weights are properties of the framework, they
should hold elsewhere. If they are properties of the task, they will move, and the
combination problem becomes real.

The enterprise row is the sharpest test, because it predicts the reverse of what we
measured: when everyone needed is already reachable, formation has no work left to do, and
the shared store that cost 11k tokens for a small gain in a pooling task should pay for
itself when the deliverable is edited jointly. It is also the row we defer---it needs a
co-edited task family rather than a reallocation of ours, and we are pursuing it as
dedicated work at a venue that can give the setting the space it needs. A framework that only ever produces
``formation dominates'' is a restatement of the task; one that predicts where formation
stops dominating, and is then held to it, is a framework.

\subsection{Edges may start public and end private}
\label{sec:lifecycle}

The framework's sharpest prediction is not about a static configuration. If the axes are
separable, an edge's position in $(F,S,A)$ can \emph{move}, and each axis unlocks the next:
open discovery supplies the second source, a sandboxed first exchange makes a stranger
affordable, repeated success is the only thing that could make an attribute mean anything
---a reputation mark is inert here precisely because nothing generated it---and shared
state is worth 11k tokens only once an edge expects to be reused. \textbf{We have not
tested it.} Every episode we ran is a cold start: 582 of them with the repeat knob present
in the harness and never turned. If an open requester's contact set narrows across
repeats, ``public versus private'' is a question about \emph{time} rather than
architecture, and a private network is what a public one becomes; if it does not, the
transition must be designed rather than left to emerge.

\else
\subsection{Edges may start public and end private}
\label{sec:lifecycle}

The framework's sharpest prediction is not about a static configuration at all. If the
three axes are separable, an edge's position in $(F,S,A)$ can \emph{move}, and the
direction is not arbitrary: each axis unlocks the next.

\begin{center}\small
open discovery $\;\rightarrow\;$ sandboxed first exchange $\;\rightarrow\;$ repeated success\\[2pt]
$\rightarrow\;$ a persistent tie $\;\rightarrow\;$ attributes worth carrying $\;\rightarrow\;$ shared state
\end{center}

Read against our results this is not speculation about human networks. Public formation is
what supplies a second source, and a second source is what our data says catches a wrong
claim. Sandboxed semantics is what makes a first exchange with a stranger affordable.
Repeated success is the only thing that could make an attribute mean anything---a
reputation mark is inert here precisely because nothing generated it. And shared state is
priced at 11k tokens, which is affordable only once an edge is expected to be used again.
Each stage pays for the next.

\textbf{This is the framework's most testable prediction and we have not tested it.} Every
episode we ran is a cold start: 582 episodes at \texttt{repeats = 1}. The harness has the
knob---a run may repeat a goal family instead of reworking one artifact---and it has never
been turned. Two things would falsify the prediction cheaply. If an open requester's
contact set does not narrow across repeats, edges do not become private on their own and
the transition must be designed rather than emergent. And if the attribute axis stays flat
even when the assertions are \emph{earned} rather than stipulated, then $w_A \approx 0$ is
a fact about text and not about cold starts.

If instead the contact set does narrow, then ``public versus private'' is a question about
\emph{time} rather than architecture, and a private network is what a public one becomes.

\paragraph{What an optimum means here.} An optimum is a configuration, not a size. On
formation it is a \emph{funnel depth}---own roster, one brokered hop, two hops, open
directory---where each layer widens reach and weakens recourse. The marginal return on a
layer is the number of \emph{independent} sources it adds, which saturates; the marginal
cost is what a claim from that layer is worth, which decays. The crossing is the depth, and
per \S\ref{sec:lifecycle} it may be a schedule rather than a constant.

\paragraph{What an optimum means here.} An optimum is a configuration, not a size. On

each additional layer widens reach and weakens recourse. The marginal return on a layer
is the number of \emph{independent} sources it adds, which saturates; the marginal cost
is what a claim from that layer is worth, which decays. The crossing is the depth. Stated
this way the optimum is measurable per scenario rather than argued per regime.
